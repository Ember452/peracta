# Peracta V0.1 持久化核心 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让一个多步 Agent 工作流在进程被 `kill -9` 之后能从断点续跑，已完成步骤不重跑。

**Architecture:** 三层单向依赖落地 —— `core`（时钟/事件/异常，零 IO）→ `journal`（SQLite append-only 事件日志 + 状态重建）→ `runtime`（`@flow` + `Context.step` 执行内核），外层一个 `cli`（argparse）。执行即"向日志追加事实"，恢复即"读日志重建已完成步骤集合，然后跳过它们"。同步 API，零运行时依赖。

**Tech Stack:** Python 3.13 · uv · ruff · pytest · 标准库 `sqlite3` / `argparse` / `dataclasses` / `enum`

**Spec:** `docs/PROJECT.md`（§2 范围、§3 验收 A1–A6、§8 任务卡 T1–T5）· `docs/STRUCTURE.md`（§3 包职责、§4 依赖方向）· `docs/FEATURES.md`（§2 A/B 域的功能意图）

> **本计划只覆盖 PROJECT.md 的 T1–T3。** T4（副作用幂等）与 T5（故障注入验证）依赖本计划冻结的 journal API，另立计划二。
> **计划位置说明**：writing-plans 技能默认 `docs/superpowers/plans/`，本项目为与既有 `docs/` 结构一致，放在 `docs/plans/`。

`tests/architecture/dependency.py`（先写被测函数）：

```python
"""Architecture guard: imports may only point to the same or a lower layer."""

from __future__ import annotations

import ast
from pathlib import Path

LAYERS: dict[str, int] = {
    "core": 0,
    "observability": 0,
    "journal": 1,
    "effect": 2,
    "runtime": 3,
    "verify": 4,
    "cli": 5,
}


def _layer_of(module: str) -> int | None:
    parts = module.split(".")
    if len(parts) < 2 or parts[0] != "peracta":
        return None
    return LAYERS.get(parts[1])


def check_dependency_direction(src_root: Path) -> list[str]:
    violations: list[str] = []
    for path in sorted(src_root.rglob("*.py")):
        relative = path.relative_to(src_root)
        # 包根 __init__.py 是公共门面，允许导出各层符号
        if relative.parent == Path("."):
            continue
        own_layer = LAYERS.get(relative.parts[0])
        if own_layer is None:
            continue
        tree = ast.parse(path.read_text(encoding="utf-8"), filename=str(path))
        for node in ast.walk(tree):
            target: str | None = None
            if isinstance(node, ast.ImportFrom) and node.module:
                target = node.module
            elif isinstance(node, ast.Import):
                for alias in node.names:
                    layer = _layer_of(alias.name)
                    if layer is not None and layer > own_layer:
                        violations.append(
                            f"{relative}: imports higher layer '{alias.name}'"
                        )
                continue
            if target is None:
                continue
            layer = _layer_of(target)
            if layer is not None and layer > own_layer:
                violations.append(f"{relative}: imports higher layer '{target}'")
    return violations
```

## Task 2: 核心机制层 `core`（时钟 / 标识 / 事件 / 异常）

> **契约（绑定）—— 本节是 Task 2 的完整需求。下方代码块仅作参考实现，不作为约束。**

**Interfaces（跨任务契约，名字与签名不得漂移）**

`errors.py` —— 全项目唯一的异常出口：
- 基类 `PeractaError(Exception)`
- `ConfigurationError(PeractaError)`
- `JournalError(PeractaError)` → `RunNotFoundError(JournalError)`、`SchemaError(JournalError)`
- `StepError(PeractaError)` → `DuplicateStepNameError(StepError)`、`StepResultNotSerializableError(StepError)`
- `FlowExecutionError(PeractaError)`，构造签名 `(run_id: str, step_name: str | None, cause: BaseException)`；必须暴露同名属性 `run_id` / `step_name` / `cause`，且 `str()` 包含 `run_id`

`clock.py`：
- `Clock` Protocol，方法 `now() -> datetime`，**必须返回带时区的 UTC 时间**
- `SystemClock`：真实时间
- `FixedClock(start: datetime)`：`now()` 返回固定值；`advance(seconds: float)` 前进；`start` 无时区时抛 `ValueError`

`ids.py`：
- `new_run_id() -> str`，前缀 `run_`，多次调用不重复
- （非确定性在此是安全的：`run_id` 一经生成即写入日志，恢复时从日志读取）

`events.py`：
- `EventKind(StrEnum)`，成员与字符串值必须**逐字**为：
  `RUN_STARTED="run_started"` · `STEP_STARTED="step_started"` · `STEP_COMPLETED="step_completed"` · `RUN_COMPLETED="run_completed"` · `RUN_FAILED="run_failed"`
- `Event`：frozen dataclass（带 `slots`），字段 `seq: int`、`run_id: str`、`kind: EventKind`、`step_name: str | None`、`payload: dict[str, Any]`（默认空 dict）、`created_at: str`

**Required behavior**
- `core` 是 L0：**不得** import 任何其它 `peracta` 子包，**不得**做 IO
- 所有公共名字带类型标注

**Acceptance（每条都要有测试；测试名可自拟，但要证明同一件事）**
1. 异常层级关系成立（`RunNotFoundError` 是 `JournalError` 是 `PeractaError`；`DuplicateStepNameError` 是 `PeractaError`）
2. `FlowExecutionError` 保留原异常对象（`cause` 同一性）且 `str()` 含 `run_id`
3. `FixedClock` 固定返回并可 `advance`；`SystemClock().now()` 带时区；`FixedClock` 拒绝无时区入参
4. `new_run_id()` 前缀为 `run_` 且两次调用不相等
5. `EventKind.STEP_COMPLETED == "step_completed"`（逐字比较）
6. `Event` 不可变：对实例字段赋值必须抛 `AttributeError`

**执行方式**：TDD —— 先写失败测试并确认失败原因正确，再实现，再确认通过。

**自由区**：函数体、测试体、docstring 措辞、辅助函数全部归实现者。偏离契约须写进报告。

```python
"""Rebuild a run's state from its event log. Pure function, no IO."""

from __future__ import annotations

from dataclasses import dataclass
from typing import Any

from peracta.core.events import Event, EventKind

STATUS_RUNNING = "running"
STATUS_COMPLETED = "completed"
STATUS_FAILED = "failed"


@dataclass(frozen=True, slots=True)
class RunState:
    run_id: str
    status: str
    completed_steps: dict[str, Any]
    inputs: dict[str, Any]


def build_run_state(events: list[Event]) -> RunState:
    if not events:
        raise ValueError("cannot rebuild state from an empty event list")

    inputs: dict[str, Any] = {}
    completed: dict[str, Any] = {}
    status = STATUS_RUNNING

    for event in events:
        if event.kind is EventKind.RUN_STARTED:
            inputs = dict(event.payload.get("inputs", {}))
        elif event.kind is EventKind.STEP_COMPLETED and event.step_name is not None:
            completed[event.step_name] = event.payload.get("result")
        elif event.kind is EventKind.RUN_COMPLETED:
            status = STATUS_COMPLETED
        elif event.kind is EventKind.RUN_FAILED:
            status = STATUS_FAILED

    return RunState(
        run_id=events[0].run_id,
        status=status,
        completed_steps=completed,
        inputs=inputs,
    )
```

```python
"""SQLite implementation. WAL + autocommit so a kill -9 loses nothing already written."""

from __future__ import annotations

import json
import sqlite3
from pathlib import Path
from typing import Any

from peracta.core.errors import RunNotFoundError
from peracta.core.events import Event, EventKind
from peracta.journal.schema import ensure_schema
from peracta.journal.store import RunRecord

_INSERT_EVENT = (
    "INSERT INTO events (run_id, kind, step_name, payload_json, created_at) "
    "VALUES (?, ?, ?, ?, ?)"
)
_SELECT_EVENTS = (
    "SELECT seq, run_id, kind, step_name, payload_json, created_at "
    "FROM events WHERE run_id = ? ORDER BY seq"
)
_SELECT_RUN = (
    "SELECT run_id, flow_name, status, created_at, updated_at, inputs_json, result_json "
    "FROM runs WHERE run_id = ?"
)


class SqliteJournal:
    """A JournalStore backed by a single SQLite file."""

    def __init__(self, path: Path | str) -> None:
        self._path = Path(path)
        self._path.parent.mkdir(parents=True, exist_ok=True)
        self._conn = sqlite3.connect(self._path, isolation_level=None)
        self._conn.row_factory = sqlite3.Row
        self._conn.execute("PRAGMA journal_mode = WAL")
        self._conn.execute("PRAGMA synchronous = FULL")
        self._conn.execute("PRAGMA foreign_keys = ON")
        ensure_schema(self._conn)

    def close(self) -> None:
        self._conn.close()

    def __enter__(self) -> SqliteJournal:
        return self

    def __exit__(self, *exc: object) -> None:
        self.close()

    def create_run(self, record: RunRecord) -> None:
        self._conn.execute(
            "INSERT INTO runs (run_id, flow_name, status, created_at, updated_at, "
            "inputs_json, result_json) VALUES (?, ?, ?, ?, ?, ?, ?)",
            (
                record.run_id,
                record.flow_name,
                record.status,
                record.created_at,
                record.updated_at,
                json.dumps(record.inputs),
                None if record.result is None else json.dumps(record.result),
            ),
        )

    def append_event(
        self,
        run_id: str,
        kind: EventKind,
        step_name: str | None,
        payload: dict[str, Any],
        created_at: str,
    ) -> Event:
        cursor = self._conn.execute(
            _INSERT_EVENT, (run_id, str(kind), step_name, json.dumps(payload), created_at)
        )
        return Event(
            seq=int(cursor.lastrowid or 0),
            run_id=run_id,
            kind=kind,
            step_name=step_name,
            payload=payload,
            created_at=created_at,
        )

    def load_events(self, run_id: str) -> list[Event]:
        rows = self._conn.execute(_SELECT_EVENTS, (run_id,)).fetchall()
        if not rows:
            raise RunNotFoundError(f"no events for run {run_id}")
        return [
            Event(
                seq=row["seq"],
                run_id=row["run_id"],
                kind=EventKind(row["kind"]),
                step_name=row["step_name"],
                payload=json.loads(row["payload_json"]),
                created_at=row["created_at"],
            )
            for row in rows
        ]

    def get_run(self, run_id: str) -> RunRecord | None:
        row = self._conn.execute(_SELECT_RUN, (run_id,)).fetchone()
        if row is None:
            return None
        return RunRecord(
            run_id=row["run_id"],
            flow_name=row["flow_name"],
            status=row["status"],
            created_at=row["created_at"],
            updated_at=row["updated_at"],
            inputs=json.loads(row["inputs_json"]),
            result=None if row["result_json"] is None else json.loads(row["result_json"]),
        )

    def set_run_status(self, run_id: str, status: str, result: Any = None) -> None:
        if self.get_run(run_id) is None:
            raise RunNotFoundError(f"unknown run {run_id}")
        self._conn.execute(
            "UPDATE runs SET status = ?, result_json = ? WHERE run_id = ?",
            (status, None if result is None else json.dumps(result), run_id),
        )

    def list_runs(self, limit: int = 50) -> list[RunRecord]:
        rows = self._conn.execute(
            "SELECT run_id, flow_name, status, created_at, updated_at, inputs_json, "
            "result_json FROM runs ORDER BY created_at DESC LIMIT ?",
            (limit,),
        ).fetchall()
        return [
            RunRecord(
                run_id=row["run_id"],
                flow_name=row["flow_name"],
                status=row["status"],
                created_at=row["created_at"],
                updated_at=row["updated_at"],
                inputs=json.loads(row["inputs_json"]),
                result=None if row["result_json"] is None else json.loads(row["result_json"]),
            )
            for row in rows
        ]
```

```python
"""Flow definition: `@flow` turns a callable into a named unit of durable work."""

from __future__ import annotations

from collections.abc import Callable
from dataclasses import dataclass
from typing import Any, TypeVar

from peracta.core.errors import ConfigurationError

F = TypeVar("F", bound=Callable[..., Any])


@dataclass(frozen=True, slots=True)
class Flow:
    name: str
    fn: Callable[..., Any]


def flow(fn: F | None = None, *, name: str | None = None) -> Any:
    """Decorate the entry point of a durable flow.

    Supports both `@flow` and `@flow(name="...")`.
    """

    def wrap(target: Any) -> Flow:
        if not callable(target):
            raise ConfigurationError(f"@flow expects a callable, got {type(target).__name__}")
        return Flow(name=name or target.__name__, fn=target)

    if fn is None:
        return wrap
    return wrap(fn)
```

```python
"""The user-facing execution surface. Every side effect of a flow passes through here."""

from __future__ import annotations

import json
from collections.abc import Callable
from typing import Any, TypeVar

from peracta.core.clock import Clock
from peracta.core.errors import DuplicateStepNameError, StepResultNotSerializableError
from peracta.core.events import EventKind
from peracta.journal.store import JournalStore

T = TypeVar("T")


class Context:
    """Handed to a flow. Records what happened so recovery can skip it."""

    def __init__(
        self,
        store: JournalStore,
        run_id: str,
        clock: Clock,
        replay: dict[str, Any] | None = None,
    ) -> None:
        self._store = store
        self._run_id = run_id
        self._clock = clock
        self._replay = dict(replay or {})
        self._seen: set[str] = set()
        self.current_step: str | None = None

    @property
    def run_id(self) -> str:
        return self._run_id

    def _stamp(self) -> str:
        return self._clock.now().isoformat()

    def step(self, name: str, fn: Callable[[], T]) -> T:
        if name in self._seen:
            raise DuplicateStepNameError(
                f"step '{name}' used twice in run {self._run_id}; "
                "make names unique (parameterise them for loops)"
            )
        self._seen.add(name)

        if name in self._replay:
            return self._replay[name]  # type: ignore[return-value]

        previous, self.current_step = self.current_step, name
        try:
            self._store.append_event(
                self._run_id, EventKind.STEP_STARTED, name, {}, self._stamp()
            )
            value = fn()
            payload = {"result": _encode(value, name)}
            self._store.append_event(
                self._run_id, EventKind.STEP_COMPLETED, name, payload, self._stamp()
            )
            return value
        finally:
            self.current_step = previous


def _encode(value: Any, step_name: str) -> Any:
    """V0.1 constraint: step results must be JSON-serialisable."""
    try:
        json.dumps(value)
    except (TypeError, ValueError) as exc:
        raise StepResultNotSerializableError(
            f"step '{step_name}' returned {type(value).__name__}, which cannot be "
            "persisted; return JSON-serialisable data"
        ) from exc
    return value
```

```python
"""Execution loop: drive a flow, record facts, survive restarts."""

from __future__ import annotations

from dataclasses import dataclass
from typing import Any

from peracta.core.clock import Clock
from peracta.core.errors import ConfigurationError, FlowExecutionError, RunNotFoundError
from peracta.core.events import EventKind
from peracta.core.ids import new_run_id
from peracta.journal.replay import STATUS_COMPLETED, build_run_state
from peracta.journal.store import JournalStore, RunRecord
from peracta.runtime.context import Context
from peracta.runtime.flow import Flow


@dataclass(frozen=True, slots=True)
class RunResult:
    run_id: str
    status: str
    result: Any = None


def execute(
    flow: Flow,
    store: JournalStore,
    clock: Clock,
    *,
    inputs: dict[str, Any] | None = None,
    run_id: str | None = None,
) -> RunResult:
    if run_id is None:
        return _start_new(flow, store, clock, inputs or {})
    return _resume(flow, store, clock, run_id)


def _start_new(
    flow: Flow, store: JournalStore, clock: Clock, inputs: dict[str, Any]
) -> RunResult:
    run_id = new_run_id()
    stamp = clock.now().isoformat()
    store.create_run(
        RunRecord(
            run_id=run_id,
            flow_name=flow.name,
            status="running",
            created_at=stamp,
            updated_at=stamp,
            inputs=inputs,
        )
    )
    store.append_event(
        run_id, EventKind.RUN_STARTED, None, {"flow": flow.name, "inputs": inputs}, stamp
    )
    return _drive(flow, store, clock, run_id, inputs, replay={})


def _resume(flow: Flow, store: JournalStore, clock: Clock, run_id: str) -> RunResult:
    run = store.get_run(run_id)
    if run is None:
        raise RunNotFoundError(f"unknown run {run_id}")
    if run.flow_name != flow.name:
        raise ConfigurationError(
            f"run {run_id} belongs to flow '{run.flow_name}', not '{flow.name}'"
        )
    state = build_run_state(store.load_events(run_id))
    if state.status == STATUS_COMPLETED:
        return RunResult(run_id=run_id, status=STATUS_COMPLETED, result=run.result)
    return _drive(flow, store, clock, run_id, state.inputs, state.completed_steps)


def _drive(
    flow: Flow,
    store: JournalStore,
    clock: Clock,
    run_id: str,
    inputs: dict[str, Any],
    replay: dict[str, Any],
) -> RunResult:
    ctx = Context(store=store, run_id=run_id, clock=clock, replay=replay)
    try:
        result = flow.fn(ctx, **inputs)
    except Exception as exc:
        store.append_event(
            run_id,
            EventKind.RUN_FAILED,
            ctx.current_step,
            {"error": repr(exc)},
            clock.now().isoformat(),
        )
        store.set_run_status(run_id, "failed")
        raise FlowExecutionError(run_id, ctx.current_step, exc) from exc

    store.append_event(
        run_id,
        EventKind.RUN_COMPLETED,
        None,
        {"result": result},
        clock.now().isoformat(),
    )
    store.set_run_status(run_id, "completed", result=result)
    return RunResult(run_id=run_id, status=STATUS_COMPLETED, result=result)
```

> **续跑必须拿到同一个 `Flow` 对象**：`execute` 在 `run_id` 不为空时使用调用方传入的 `flow`，并校验 `run.flow_name == flow.name`，不匹配抛 `ConfigurationError`。CLI 的 `resume` 子命令因此需要文件参数（见 Task 5）。

```python
"""Command line entry point. Exit codes: 0 ok, 1 run failed, 2 usage error."""

from __future__ import annotations

import argparse
import importlib.util
import sys
from pathlib import Path
from typing import Any

from peracta.core.clock import SystemClock
from peracta.core.errors import ConfigurationError, PeractaError
from peracta.journal.sqlite_store import SqliteJournal
from peracta.runtime.executor import execute
from peracta.runtime.flow import Flow

DEFAULT_DB = Path(".peracta/journal.sqlite")
EXIT_OK = 0
EXIT_FAILED = 1
EXIT_USAGE = 2


def _load_flow(path: Path) -> Flow:
    if not path.is_file():
        raise ConfigurationError(f"no such flow file: {path}")
    spec = importlib.util.spec_from_file_location("_peracta_user_flow", path)
    if spec is None or spec.loader is None:
        raise ConfigurationError(f"cannot import {path}")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    candidate: Any = getattr(module, "flow", None)
    if not isinstance(candidate, Flow):
        raise ConfigurationError(f"{path} must define a module-level `flow` object")
    return candidate


def _parse_inputs(pairs: list[str]) -> dict[str, Any]:
    inputs: dict[str, Any] = {}
    for pair in pairs:
        key, _, raw = pair.partition("=")
        if not _ or not key:
            raise ConfigurationError(f"--input expects key=value, got {pair!r}")
        inputs[key] = _coerce(raw)
    return inputs


def _coerce(raw: str) -> Any:
    try:
        return int(raw)
    except ValueError:
        pass
    if raw.lower() in {"true", "false"}:
        return raw.lower() == "true"
    return raw


def _build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="peracta", description="Durable execution kernel")
    parser.add_argument("--db", type=Path, default=DEFAULT_DB, help="journal file path")
    sub = parser.add_subparsers(dest="command", required=True)

    run_cmd = sub.add_parser("run", help="start a new run")
    run_cmd.add_argument("file", type=Path)
    run_cmd.add_argument("--input", action="append", default=[])

    resume_cmd = sub.add_parser("resume", help="continue an interrupted run")
    resume_cmd.add_argument("run_id")
    resume_cmd.add_argument("file", type=Path)

    ps_cmd = sub.add_parser("ps", help="list runs")
    ps_cmd.add_argument("--limit", type=int, default=20)
    return parser


def main(argv: list[str] | None = None) -> int:
    parser = _build_parser()
    args = parser.parse_args(argv)
    clock = SystemClock()

    try:
        with SqliteJournal(args.db) as journal:
            if args.command == "run":
                flow_obj = _load_flow(args.file)
                result = execute(
                    flow_obj, journal, clock, inputs=_parse_inputs(args.input)
                )
                print(f"{result.run_id} {result.status} result={result.result!r}")
                return EXIT_OK
            if args.command == "resume":
                flow_obj = _load_flow(args.file)
                result = execute(flow_obj, journal, clock, run_id=args.run_id)
                print(f"{result.run_id} {result.status} result={result.result!r}")
                return EXIT_OK
            for record in journal.list_runs(limit=args.limit):
                print(f"{record.run_id}  {record.flow_name}  {record.status}  {record.created_at}")
            return EXIT_OK
    except ConfigurationError as exc:
        print(f"error: {exc}", file=sys.stderr)
        return EXIT_USAGE
    except PeractaError as exc:
        print(f"error: {exc}", file=sys.stderr)
        return EXIT_FAILED


if __name__ == "__main__":
    raise SystemExit(main())
```

> 注：`resume` 子命令需要 `file` 参数（要拿到同一个 `Flow` 对象）。这是有意设计，不是遗漏 —— 已在 `execute` 的契约里说明。
